# Pult

Страница входа в Max (как на web.max.ru) и Telegram-бот для выгрузки сессий.

## Запуск

```bash
npm install
npm start
```

- **Вход / авторизация:** http://127.0.0.1:3780 — QR или SMS, сессия сохраняется в `sessions/max_*.json`
- **Пульт (чаты):** http://127.0.0.1:3780/desk
- **Telegram-бот:** `node bot/index.js` — выгрузка сессий из `sessions/`

Пароль панели при первом запуске печатается в консоли и сохраняется в `.panel-secret`. Можно задать свой: `PANEL_PASSWORD=... npm start`.

## Вход

1. Введите пароль пульта.
2. Нажмите «Показать QR» и отсканируйте его в Max: профиль → устройства.
3. Либо войдите по SMS. Либо «Продолжить сохранённую сессию», если файл уже есть.

После входа можно читать чаты, писать, слать фото, править и удалять свои сообщения, смотреть устройства и править профиль.

## Telegram-бот @maxlarpingbot

Отдельный процесс для выгрузки и загрузки `sessions/*.json` через кнопки.

```bash
npm run bot
```

Настройки в `.env`:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather
- `TELEGRAM_ADMIN_IDS` — ваш numeric id (через [@userinfobot](https://t.me/userinfobot))
- `TELEGRAM_SUPPORT_CHAT_ID` / `TELEGRAM_COMMUNITY_CHAT_ID` — id чатов для обязательной подписки

Перед запуском добавьте бота в [поддержку](https://t.me/+2-6zGMqnW1VmZTM1) и [чат](https://t.me/+5-HGP3yLl2piZDQ1), затем в каждом чате выполните `/chatid` и впишите id в `.env`.

При `/start` бот проверяет подписку, потом показывает меню: список, скачать, все файлы, загрузить. Поддержка: @zprep.

## Важно

Слушает только `127.0.0.1`. Если выставить `HOST=0.0.0.0`, любой, кто откроет сайт и знает пароль, получит ваш аккаунт Max. Файл `sessions/*.json` — полный вход, его не коммитить и не слать третьим лицам.
